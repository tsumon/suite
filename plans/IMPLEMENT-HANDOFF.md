## 怎么试（Windows 真机）

### 编

打开 `src\Suite.sln`，配置 **Debug | x64**，生成解决方案。

或：

```bat
dotnet build src\Suite.sln -c Debug -p:Platform=x64
dotnet test  src\Suite.sln -c Debug -p:Platform=x64
```

`TaskbarFx.Native.dll` 必须用 VS / MSBuild 编 C++ 工程。`dotnet` 不会变出这份 DLL。没有 DLL 时，设置页会说「无法启用任务栏效果。截图和网速仍可用。」——这是失败人话，不是假成功。

产出（路径以实际为准）：

```
src\Suite.App\bin\x64\Debug\net10.0-windows10.0.19041.0\Suite.exe
src\Suite.App\bin\x64\Debug\net10.0-windows10.0.19041.0\TaskbarFx.Native.dll
```

同目录有 `TaskbarFx.exe` 也没关系，**主程序不会去启动它**。`TaskbarFx.Host` 是可选/废弃，只留 `--reset` 和旧安装。

### 截图 / 贴图

1. `Ctrl+Shift+F12` 或托盘「区域截图」→ 全屏压暗，十字光标，左上角：`悬停点窗，拖动手选。松手钉图。Esc 取消。`
2. 鼠标移到记事本客户区 → 红描边框住那块（窗外压暗，窗内不压暗）。单击 → 那块 **1:1 钉在原地**，遮罩立刻没了，剪贴板能贴到画图。
3. 拖一块松手 → 钉；拖的时候选区外有 `235 × 172` 这种尺寸片。
4. Esc 或右键：整次当没截过。没有遮罩、没有新贴图、剪贴板没被这次写入。
5. Shift+松手 → 才进标注。标注是贴在原选区上的图 + 右键菜单（矩形/箭头/文字/马赛克/复制/钉图/取消），或靠近边缘才出现的深色文字条。**没有**厚白图标工具栏。标注里 Esc 仍整次取消。
6. 贴图：只有图 + 向外光环。没有 ×、没有「穿透」按钮、没有「滚轮缩放…」标题条。拖、滚轮缩放、Alt+滚轮透明度、右键菜单、Esc/Delete 关这一张。

主路径任何时候都不该看到 `plans/joe-hate-toolbar-ref.png` 那种厚白图标栏。

### 网速

1. 干净启动：任务栏通知区左侧附近有 `↓` `↑`，桌面上没有网速方块。
2. 嵌不进去（或 Win11 把槽挤没）：一条气泡，标题 `Suite`，正文含「无法钉到任务栏」和「已改用桌面悬浮窗」，桌面出现可拖方块。只提示一次。
3. 设置里去掉「钉在任务栏」再应用：只有悬浮，**不**报失败。
4. 托盘是「隐藏网速」/「显示网速」，不要「显示网速窗」。

### 任务栏效果（同进程）

1. 设置「任务栏效果」：勾选「启用任务栏效果」；档位四个中文名 **系统默认 / 实色 / 全透明 / 亚克力**，不要英文当唯一标签。
2. 现代 Win11：状态必须是「Win11 路径未交付。截图和网速仍可用。」**不是**「已应用」。截图热键仍可用。刚打开开关时可以再弹一次气泡。
3. Win10 经典栏：点应用后状态「任务栏效果已应用。」（SWCA，同进程加载 Native DLL）。
4. 关掉开关并应用：任务栏回到系统默认，状态「任务栏效果已关闭。」不要去结束 explorer。

帮助句会写：透明挂住时截图也可能一起挂（已知取舍）。这是 Joe 拍的单进程。

## 没做 / 不要误会

- **没有**抄 Snipaste / ShareX / TrafficMonitor / TranslucentTB 源码。选窗是 `WindowFromPoint` + UI Automation。
- **没有** Win11 TAP / 注入 explorer。Win11 现代栏就是「未交付」+ 人话。
- `TaskbarFx.exe` 不是主路径。主路径是 Suite 加载 `TaskbarFx.Native.dll`。
- 标注仍是四件套：矩形、箭头、文字、马赛克。不加铅笔、编号、双向箭头。
