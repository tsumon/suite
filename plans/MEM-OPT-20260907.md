## 已修

1. **AnnotationWindow.ReleaseSessionBuffers**：`ReleasePixels` + `_freezeImage.Source`/`_freezeSource`/`_preview.Source` 置 null，清 draft。
2. **CaptureService**：cancel / cancel-annotate / Finish 后 `GC.Collect(2, Optimized)`（文档化；主路径仍靠 `ReleasePixels`）。F1 连按仍由 `_busy` 挡，无双会话帧泄漏。
3. **Pinboard / PinWindow**：Pin 时 Freeze；Closed 时 `Picture.Source = null`。
4. **ScrollCapture**：每步释放旧 stitch / previous / next；cancel/done 走 finally；成功交接后 tiny placeholder 再释放。
5. **ScreenshotHistory / HistoryWindow**：`OnLoad` 解码；Reload / Closed 清空 Thumb。
6. **NetSpeedTrayWidget**：复用 `_frameBuffer`，Dispose 清空。
7. **RegionOverlay / ColorPick**：Closed 清 backdrop + magnifier Source。

## 审计摘要（Allocate / Clone / FromBitmapSource）

- 抓取：`GdiBitBlt` / D3D → 会话 `ReleaseFrames` / `ReleaseSessionBuffers` / ColorPick Closed。
- Crop / Bake / OCR clone：对应路径有 `ReleasePixels`。
- Scroll：步进释放 + finally；调用方 `AppController` 成功/失败后 `ReleasePixels` + 可选 GC。
- `FromBitmapSource`（文字标注 Bake）：进入 `_cachedBake`，会话结束释放。
