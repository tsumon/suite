# Plan — Suite P0

落地 ADR §7 无注入骨架：远程 Grok 按 `src/` 切分写出 C# / .NET 10 / WPF，Joe 审 diff；**Debian 远程只出码，不把 WPF 当已编过**；`dotnet build` 与全部 UI 验证只在 Windows 真机（VS 2026 / MSBuild 18.0+，x64）。P0 退出：无 TaskbarFx 也能当「主题 + 网速」托盘小工具用。

## Scope
- In:
  - `src/Suite.sln` + `src/Directory.Build.props`（`net10.0-windows`、nullable、警告当错误、x64）
  - `Suite.App` 托盘常驻、命名 Mutex 单实例、`%LOCALAPPDATA%\Suite\settings.json` 唯一写入、`HKCU\...\Run` 开机启动可逆
  - `Suite.ThemeToggle`：同时翻转 `AppsUseLightTheme` + `SystemUsesLightTheme`，`SendMessageTimeoutW` + `ImmersiveColorSet`，不杀 explorer；本进程网速窗换色（可先占位色块）
  - `Suite.NetSpeed` 桌面悬浮：`GetIfTable2` / `GetIfEntry2`、1 s 采样、选网卡、置顶可拖；睡眠恢复后非恒 0
  - `RegisterHotKey` 占位：按下有托盘气泡或日志、不崩；不实现截图/贴图
  - `tests/Suite.Contracts.Tests`、`Suite.ThemeToggle.Tests`、`Suite.NetSpeed.Tests`（无 UI 可跑）
  - Windows 真机可验证：杀进程再开只有一份；Run 键可逆；设置里颜色与任务栏/窗口浅深一起变；传文件时网速数字变化
- Out:
  - `TaskbarFx.Host` / `TaskbarFx.Native`、命名管道 IPC、任何 explorer 注入 / SWCA / TAP
  - `Suite.Capture` / `Suite.Pinboard` 完整实现（热键只占位）
  - 安装包（Inno / WiX）、MSIX、Authenticode、GitHub remote
  - 视觉定稿、WinUI 3、网速 `SetParent` 进任务栏、动态模式、ARM64、便携 zip
  - 抄 GPL / Anti-996 源码；来路不明 NuGet；默认管理员 / 内核驱动

## Action items
- [ ] 在 Windows 真机核对工具链：`dotnet --info` 须见 .NET 10 SDK；确认 VS 2026 / MSBuild 18.0+。远程 Debian **禁止**用 `dotnet build` 冒充绿；后续每步「编 / 跑 / 点」都标在 Joe 的 Windows 机。
- [ ] 搭建 P0 工程树：新增 `src/Suite.sln`、`src/Directory.Build.props`、`src/Suite.Contracts/`、`src/Suite.Platform/`、`src/Suite.NetSpeed/`、`src/Suite.ThemeToggle/`、`src/Suite.App/`（WinExe + UseWPF，输出 `Suite.exe`）及对应 `tests/`；写根 `.gitignore`（`bin/` `obj/` `*.user`、证书）。**不建** TaskbarFx / Capture / Pinboard。Joe 审 sln 形状后，Windows 执行 `dotnet build src/Suite.sln -c Debug`。
- [ ] 实现设置契约与持久化：在 `Suite.Contracts` 放 schema（开机启动、网卡 IfIndex、热键占位、网速窗位置）；`Suite.App` 读写 `%LOCALAPPDATA%\Suite\settings.json`（Suite 唯一写入者）。Windows：改开关、杀进程再开，JSON 与行为仍在。
- [ ] 实现 `Suite.Platform` 壳：命名 Mutex 单实例（第二份启动立即退出）；`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入/删除可逆；`RegisterHotKey` 占位回调只弹气泡或写日志，**不得**等管道或拉起 TaskbarFx。Windows：连开两次只有一份；勾/去勾开机启动后 `reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 值出现/消失。
- [ ] 实现 `Suite.ThemeToggle`：读-翻-写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize` 两 DWORD，再 `SendMessageTimeoutW(HWND_BROADCAST, WM_SETTINGCHANGE, 0, L"ImmersiveColorSet", SMTO_ABORTIFHUNG, ~5000)`；进程内 `ThemeChanged` 刷新网速窗；**禁止** `taskkill` explorer。Windows：设置面板颜色与任务栏/窗口浅深一起变；网速窗换色。
- [ ] 实现 `Suite.NetSpeed`：后台线程调 `GetIfTable2` / `GetIfEntry2`，用 ΔInOctets / ΔOutOctets / Δt；桌面 `Topmost` 可拖 WPF 窗；手动选网卡 + 刷新；订阅 `SystemEvents.PowerModeChanged`，睡眠恢复后重新枚举接口。Windows：传文件时数字变化；睡眠再唤醒后非恒 0。
- [ ] 接线 `Suite.App` 托盘：`NotifyIcon` 用 P/Invoke `Shell_NotifyIcon` 或 WinForms 互操作（不引入来路不明 NuGet）；菜单含翻转主题、显示/隐藏网速窗、设置、开机启动、退出。设置窗只做功能，不定视觉。Windows 按 ADR §7 P0 表走完托盘 / 主题 / 网速 / 热键占位。
- [ ] 补测试与交接：Windows 跑 `dotnet test src/Suite.sln -c Debug`（至少 Contracts / ThemeToggle / NetSpeed；ThemeToggle 测编排时注入假注册表，不写真 HKCU）。风险边：睡眠后 IfIndex 变化导致恒 0、热键与系统 PrtScr 互抢（设置可改键即可）。远程在本计划注明「未在 Debian 编过 WPF」。Joe 审 diff 后才标 P0 完成。
