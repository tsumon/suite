# 网速钉任务栏 + 任务栏效果设置规格

权威视觉：根目录 `DESIGN.md`。本文只定 **网速默认钉任务栏** 的表现、外观设置、失败人话与回退，以及 **任务栏透明/亚克力** 在设置页的开关、档位、文案。

任务栏透明由 Suite **同进程内模块**负责（不再拉起独立 `TaskbarFx.exe`）。本文不写注入、SWCA、TAP 细节。Joe 拍板：透明与主程序同进程，接受透明挂了截图也可能挂；设置页仍保留开关/档位/失败人话。

学 TrafficMonitor **行为与设置项**。不抄源码（Anti-996）。颜色选择器用系统对话框。

---

## 1. 两件不要混的事

| | 网速钉任务栏 | 任务栏效果 |
| --- | --- | --- |
| 谁 | Suite 同进程里的网速窗 | Suite **同进程内**任务栏效果模块 |
| 干什么 | 把 ↑↓ 速率嵌进任务栏 | 改任务栏透明/实色/亚克力 |
| 失败 | 人话 + **立刻改桌面悬浮** | 人话 + **不改系统任务栏**（模块失败不等于整进程必崩，但同进程无硬隔离） |
| 默认 | **开**（可见 + 嵌入） | **关**（不改系统外观，直到用户打开） |

用户可以只要网速、不要透明，或反过来。两个开关互不隐含。

## 2. 网速：默认钉任务栏

### 2.1 默认

- `显示网速` = 开
- `钉在任务栏` = 开
- 开机后先尝试嵌入主任务栏（通知区左侧槽），成功则不出现桌面方块。
- 外观默认见 §3.2。旧 `settings.json` 缺新字段时用这些默认，不强制 bump schema。

### 2.2 任务栏槽（成功）

反例：`design/joe-netspeed-ugly.png`（双行顶对齐、底下一大块空、1px 框、字 11px）。按旧 token 做出来的，不是「没按 DESIGN.md」。本轮 token 已改，实现跟新 token。

- 位置：主任务栏 `Shell_TrayWnd` 客户区，通知区左侧。宽 148 物理像素；**高 = 任务栏客户区高**（`TaskbarEmbed.ComputeSlot` 已返回客户区高）。窗体高度必须等于该值换成的 DIP，**禁止再锁 40 DIP**。
- 样子：直角 `{rounded.none}`、**默认无框**、透明底、不可拖。不要品牌描边。可选「显示边框」才画 1px、约 16% 不透明的浅/深线。
- 字：Consolas（缺则 Cascadia Mono）。默认 **13px**、行高 **1.05**、字重 400。用户可调 10–18，只改槽。等宽数字，避免宽度乱跳把图标挤走。
- 两行默认：`↓ 12.3 KB/s` 在上，`↑ 1.0 KB/s` 在下。
- 垂直：速率块在槽里 **光学垂直居中**。禁止 `StackPanel` 默认顶对齐。Consolas 视觉重心略偏上，允许内容块整体下移 1 DIP。宁可微偏下，不要再偏上。不要靠加大 `Padding` 把空从底下挪到顶上。
- 跟系统浅/深色：未自选行颜色时，深任务栏用 `{colors.ink-dark}`，浅任务栏用 `{colors.ink-light}`。`0 B/s` 用 `{colors.netspeed-zero}`。自选行颜色后，该行（含 0）都用所选色。
- 不进任务栏缩略图、不进 Alt+Tab、不 `ShowInTaskbar`。

#### 2.2.1 槽垂直度量（coding 用纯函数，Debian 可红可绿）

输入：任务栏客户区高（物理像素）、DPI、字号 DIP、行高、可见行数（1 或 2）。

```
windowHeightDip = PixelsToDip(trayClientHeightPx, dpi)
contentHeightDip = fontSizeDip × lineHeight × visibleLineCount
leftover = windowHeightDip − contentHeightDip
offsetYDip = leftover / 2 + 1        // +1 DIP 光学下移；内容高于槽时 offsetYDip = 0，允许裁切
windowWidthDip = PixelsToDip(148, dpi)
padLeft = padRight = 8               // {spacing.taskbar-pad} 的水平
padTop = padBottom = 0               // 垂直不靠 padding
```

硬编码窗高 40 DIP = 红。高度跟客户区且 `offsetYDip` 让内容块居中 = 绿。

真机观感（字是否「看起来」居中、底下是否空）Debian 测不了，不要拿 `dotnet test` 绿冒充 `joe-netspeed-ugly.png` 已修。

### 2.3 桌面悬浮（仅回退或用户关掉「钉在任务栏」）

- 168×56 DIP，圆角 6px，可拖，置顶。
- 字 Consolas **13px**（`{typography.rate}`），**不跟**任务栏字号走。
- 行颜色、显隐、着色与槽共用。
- 「背景透明」只作用于槽。悬浮在桌面上默认 `{colors.surface-light}` / `{colors.surface-dark}` 底板；用户关掉透明并选了着色，悬浮改用该色。
- 位置写入设置，下次还在。
- 嵌入成功时不要同时留一个悬浮幽灵窗。

### 2.4 失败 → 人话 + 回退

嵌入失败或事后心跳发现掉了：**只提示一次**，然后 `ShowAsFloating()`。不要死循环抢 `SetParent`，不要假装还在任务栏。

**气泡标题：** `Suite`

**气泡 / 设置状态共用句式：**

`无法钉到任务栏，已改用桌面悬浮窗。{原因}`

原因用下面这些，拼在句点后，带空格：

| 探测到的情况 | 原因短语 |
| --- | --- |
| 找不到任务栏窗 | 找不到任务栏。 |
| `SetParent` 没挂上 | 系统不允许把网速嵌进去。 |
| 摆放失败 | 任务栏里没有足够位置。 |
| 读客户区失败 | 无法读取任务栏大小。 |
| Win11 居中栏/小组件把槽挤没 | 任务栏布局不允许嵌入。 |
| 其它 Win32 | 保留简短人话；不要只丢 `Win32 5`。 |

整句示例：

`无法钉到任务栏，已改用桌面悬浮窗。任务栏布局不允许嵌入。`

用户关掉「钉在任务栏」再应用：**静默**改悬浮，不报失败（这是选项，不是故障）。

用户关掉「显示网速」：卸嵌入、隐藏窗，不报失败。

### 2.5 其它网速状态

每态都要有样子。只显一行时，那一行仍在槽里垂直居中。

| 状态 | 显示 | 额外 |
| --- | --- | --- |
| 正常双行 | `↓ {速率}` / `↑ {速率}` | 1 秒刷新，无数字滚动 |
| 只显下行 | 仅 `↓ {速率}`，垂直居中 | 「显示上行」关 |
| 只显上行 | 仅 `↑ {速率}`，垂直居中 | 「显示下行」关 |
| 可选单行 | `↓ {速率}  ↑ {速率}` 一行居中 | 默认关。宽仍 148，超出裁切，不自动加宽 |
| 睡眠刚醒 | 允许 1–2 秒空窗，然后恢复，禁止恒 `0 B/s` | 不弹「已恢复」 |
| 网卡没了 | `↓ —` / `↑ 选网卡`（只显示仍勾选的行） | 设置状态可写「找不到上次的网卡，请选一块。」 |
| 嵌入失败 | 人话 + 悬浮 | §2.4 |
| 管理员进程 | 网速仍可显示；另有开机启动警告 | 不把管理员当嵌入失败原因除非真失败 |

速率文案已有格式器则沿用；`0 B/s` 只表示真的空闲，不表示坏了。

### 2.6 托盘

| 网速可见 | 菜单 |
| --- | --- |
| 开 | 隐藏网速 |
| 关 | 显示网速 |

不要写「显示网速窗」——默认已经不是悬浮窗。双击托盘仍开设置。

主题项见 §5：托盘首项「切换系统深浅色」是系统浅/深色**主入口**。

## 3. 设置页 · 网速

分组标题：`网速`。控件排在这一组里，不要另开「外观」页或侧栏。点「应用」才写入槽/悬浮；拖字号滑块不要实时改任务栏。

### 3.1 显隐与位置（已有，文案不动）

| 控件 | 文案 | 默认 |
| --- | --- | --- |
| 勾选 | 显示网速 | 开 |
| 勾选 | 钉在任务栏 | 开 |
| 帮助 | 默认嵌进主任务栏。嵌不进去会告诉你，并改用可拖的桌面悬浮窗。取消勾选则只用悬浮窗。 | — |
| 下拉 | 网卡列表，`{别名} (IfIndex {n})`，断开加 ` [down]` | 当前绑定 |

### 3.2 外观（TrafficMonitor 级，本轮必加）

学项，不抄 MFC 对话框。存盘字段给 coding：缺字段 = 下表默认，优先不 bump `CurrentSchemaVersion`。

| 控件 | 文案 | 存盘（建议名） | 默认 | 范围 / 行为 |
| --- | --- | --- | --- | --- |
| 标签 + 滑块 + 数字 | 字号 | `FontSizeDip` | `13` | 10–18，步进 1。**只改任务栏槽。** |
| 帮助 | 只改任务栏里的字。桌面悬浮窗仍是 13。 | — | — | 不复述「字号」。 |
| 勾选 | 显示下行 | `ShowDownload` | 开 | 关则槽/悬浮不画 `↓`。 |

| 标签 + 16×16 色块 + 按钮 | 下行颜色 | `DownColorArgb` | 空 = 跟系统 ink | 按钮「选颜色」，系统 `ColorDialog`。 |

| 控件 | 文案 | 存盘 | 默认 |
| --- | --- | --- | --- |
| 勾选 | 显示边框 | `ShowBorder` | 关 |

### 3.3 明确不做（`/distill`）

不要出现在网速组：CPU / 内存 / GPU / 温度、历史流量、皮肤、插件、WinRing0、副屏任务栏网速、实时预览。

## 4. 设置页 · 任务栏效果（只定开关 / 档位 / 文案）

实现与注入细节不在本文。设置页是用户唯一要理解的面；效果模块跑在 Suite 同进程内。

### 4.1 开关

- **标题：** `任务栏效果`
- **勾选：** `启用任务栏效果`
- **帮助（开关下，必留）：**

`与 Suite 同一进程内的任务栏效果模块。关掉并点应用，恢复系统默认。不要结束 explorer。透明挂住时截图也可能一起挂（已知取舍）。`

不要写 DLL、管道、TAP、SWCA。用户不需要这些词。

### 4.2 档位（下拉，中文在前）

默认档在开关**打开时**为亚克力。开关关闭 = 行为上等于系统默认，不必强行改下拉。

| 存盘值 | 下拉文案 | 帮助里的一句话（下拉下方，随当前档换） |
| --- | --- | --- |
| `normal` | 系统默认 | 不改任务栏外观。 |
| `opaque` | 实色 | 任务栏铺满所选颜色，不透明。 |
| `clear` | 全透明 | 任务栏完全看穿。图标还在。 |
| `acrylic` | 亚克力 | 磨砂半透明。 |

禁止只写 `Normal` / `Opaque` / `Clear` / `Acrylic` 当唯一标签。括号英文不要。档位名已经是中文。

v1 **不下发** Blur、动态模式（有窗/最大化/开始菜单）。设置里不要出现这些选项。

### 4.3 颜色与透明度

| 控件 | 文案 |
| --- | --- |
| 标签 | 颜色 |
| 按钮 | 选颜色 |
| 标签 | 透明度 |
| 滑块旁数字 | `0`–`255`（alpha）。不要改成 0%–100% 除非同时改存盘，避免两套数。 |

帮助：

`实色会忽略透明度。全透明和亚克力才用上面的透明度。`

颜色选择器用系统对话框，不要自绘作品集取色盘。

### 4.4 状态句（设置页常驻一行 + 必要时气泡）

| 情况 | 文案 |
| --- | --- |
| 开关关，已恢复 | 任务栏效果已关闭。 |
| Win10/经典栏，已套上 | 任务栏效果已应用。 |
| 现代 Win11 XAML 栏 | Win11 路径未交付。截图和网速仍可用。 |
| 模块初始化失败 | 无法启用任务栏效果。截图和网速仍可用。 |
| 套用失败 | 无法应用任务栏效果。{短原因}截图和网速仍可用。 |
| 杀软拦住 | 任务栏效果被安全软件拦住。截图和网速仍可用。 |

硬规则：

- **不准**在 Win11 未交付路径上显示「已应用」。
- **不准**让用户去「结束 explorer 试试」。
- 失败句末尾带 `截图和网速仍可用`（模块级失败时尽量如此；同进程无硬隔离，不承诺「崩了也不影响」）。
- 气泡标题仍是 `Suite`。Win11 未交付用设置状态即可；用户刚打开开关却不可用时，再弹一次气泡。

### 4.5 开关与档位的交互（设置语义）

1. 勾上启用 + 点应用 → 启用同进程内任务栏效果模块，按当前档位尝试。失败走 §4.4，开关可以保持勾选（表示用户意图），但状态必须说没套上。实现若自动取消勾选，必须同时改状态句，不能静默。
2. 去掉勾 + 点应用 → 恢复系统默认（档位 `normal` 的效果），模块停用/卸效果。状态：`任务栏效果已关闭。`
3. 只改颜色/档位没点应用 → 不预览到系统任务栏（避免拖滑块把桌面闪花）。v1 无实时预览。
4. Suite 退出：默认保持最后一次外观（不闪任务栏）。这不是设置页上的开关；v1 不把「退出后保持外观」暴露成第三勾选，以免和「启用」打架。

## 5. 主题与网速、任务栏效果的边界

**主入口：托盘右键「切换系统深浅色」。** 不必进设置。实现已有（`TrayIconService` 首项 → `ToggleTheme`）。文案就是这七个字，不要写成「翻转主题」「显示网速窗」。

设置页「常规」留**次要**按钮，文案同样是「切换系统深浅色」。帮助指向托盘。详见 `design/SETTINGS-PAGE-SPEC.md`。

改的是 **系统浅/深色**（Apps + System），不是任务栏亚克力，也不是本程序自己的皮肤。

| 动作 | 网速 | 任务栏效果 |
| --- | --- | --- |
| 切换成功 | 悬浮/槽换默认字色与底（用户自选行颜色保持） | 不自动开关效果 |
| 主题写入失败 | 气泡：`无法写入主题设置。可能被策略锁定。` | 不动 |
| 广播半成功 | `已写入浅色，但广播未完成。未结束 explorer。` | 不动 |

成功气泡用人话：`已切换为浅色。` / `已切换为深色。` 不要把 `Apps + System` 写进必须看见的句子。

帮助（设置页次要按钮下）：

`主入口在托盘右键。这里也可以切。改的是系统应用和任务栏的浅/深色，不是任务栏亚克力。不结束 explorer。若本机还在跑 Auto Dark Mode，两程序会抢。`

不要在帮助里堆 `AppsUseLightTheme` / `ImmersiveColorSet`。

## 6. 运动与反模式（短判断）

- 网速数字 1 秒一跳，不要数字滚动动画。
- 嵌入失败回退悬浮：窗直接出现在上次坐标，不要从任务栏飞出。
- 设置打开不要入场。
- 设置页就是系统表单。不要做成三卡片「网速 / 透明 / 主题」营销栅格。
- 任务栏槽里禁止大圆角、紫条、品牌 Logo、默认 1px 方框。

## 7. 验收

1. 干净安装：任务栏右侧附近能看到 ↑↓，桌面上没有网速方块。字按 13px 扫得清；两行在槽里垂直居中，底下不再空一截（对照 `design/joe-netspeed-ugly.png`）。
2. 人为让嵌入失败（或 Win11 挤占）：一条气泡含「无法钉到任务栏」和「已改用桌面悬浮窗」，桌面出现可拖方块。
3. 去掉「钉在任务栏」再应用：只有悬浮，无失败气泡。
4. 「启用任务栏效果」在现代 Win11：状态是「Win11 路径未交付」，不是「已应用」；截图热键仍可用。
5. 关掉任务栏效果并应用：任务栏回到系统默认；文案为「任务栏效果已关闭。」
6. 档位四个中文名都能看见，无纯英文唯一标签。
7. 网速组能改字号、上/下行颜色、显隐行、背景透明/着色；点应用后槽跟着变，没点应用不变。
8. 只留下行：槽里一行 `↓`，仍垂直居中。
9. 托盘右键第一项是「切换系统深浅色」，点了不必开设置就能切系统浅/深。
10. 旧 schema 2 的 `settings.json` 打开不炸，钉栏保持，新外观字段用默认。
