## 3. 恢复默认

### 3.1 入口

| 位置 | 控件 | 文案 |
| --- | --- | --- |
| 设置 · **关于** 组末 | 次要系统按钮（左对齐） | `恢复默认设置` |

不要放常规组顶、不要做成主色大按钮、不要 Lucide。

### 3.2 确认（破坏性）

点按钮 → 系统确认框：

- 标题：`恢复默认设置？`
- 正文：`网速外观、任务栏效果、截图选项等会回到默认。不会卸载 Suite，也不会删你已保存的截图文件。`
- 按钮：`恢复`（默认/危险侧重右）· `取消`

### 3.3 状态

| 状态 | 行为 |
| --- | --- |
| 确认后 | 写盘默认值 → `ApplySettings` → 底栏 `已恢复默认。` |
| 取消 | 无变更 |
| 失败 | `没能恢复默认，请再试一次。`（底栏；控件保持确认前） |

默认值权威：各 SPEC 的默认行（网速 §3.2、截图热键 F1、自动钉关、任务栏效果关等）。缺字段 = 打开时已用的那套默认。

## 4. 浅色主题 + 透明 / 亚克力提示

问题：系统**浅色**时，任务栏「全透明 / 亚克力」+ 网速**背景透明**易导致字看不清。

### 4.1 何时出现

同时满足（设置页内联帮助，`typography.settings-help` + `settings-muted`）：

1. 系统应用主题为**浅色**（或用户刚切到浅色），且  
2. 「启用任务栏效果」开，且档位为 **全透明** 或 **亚克力**，**或** 网速「背景透明」开  

显示一行提示（不弹窗、不挡控件）：

> `浅色主题下，透明任务栏上的网速可能看不清。可关「背景透明」、给下行/上行选深色，或把任务栏效果改成实色。`

### 4.2 行为

| | |
| --- | --- |
| 出现 | 条件满足即显示；改完即刷新（跟自动存盘同一拍） |
| 消失 | 条件不满足立刻撤掉 |
| 不要 | 红框闪、强制改用户选项、切主题时自动关透明 |

托盘切浅色成功后：若设置窗开着，同一提示按条件更新；关着则下次打开再算。

## 6. 验收（Windows 真机）

1. 松手栏有识字图标、无中文大按钮；tooltip「识字」；成功见「已复制文字。」  
2. 托盘有「滚动长截图」；F1 路径不变。  
3. 关于里「恢复默认设置」→ 确认框 → 底栏「已恢复默认。」  
4. 浅色 + 透明/亚克力时设置里出现 §4 提示句；改实色或关掉透明后提示消失。  
5. 无 Oops、无入场动画、工具栏仍浅色图标条。
