# Suite 交互 P2 — Operate 切片

日期：2026-09-06。服从根目录 `DESIGN.md`。P1 见 `INTERACTION-P1.md`。  
本页：**更新通道、崩溃/透明兜底、截图历史、贴图管理与穿透快捷键、放大镜、取色、副屏网速、网速拖位、浅色一键亚克力、冒烟脚本、日志开关**。  
**不做：** 代码签名 / 公证 / 安装包证书流程。

**模式：** Operate。工具栏仍 **图标 + tooltip、栏上无字**。设置仍是系统表单、改完即写盘。失败说人话，禁止 Oops。

> 覆盖关系：本文件打开的能力，以本页为准；旧文「本轮不做放大镜/取色/历史/副屏」等（如 `CAPTURE-PIN-SPEC` / `SETTINGS` §0）在 P2 交付范围内作废，其它条款仍有效。

## 0. 总原则

| 原则 | 落地 |
| --- | --- |
| 第 100 次一样快 | 无作品集入场；放大镜/取色跟手，不播片头 |
| pointing-beats-describing | 松手栏只加图标键；列表/设置用系统控件 |
| 改完即生效 | 同 P1 / `SETTINGS-PAGE-SPEC` §7 |
| 破坏性要确认 | 清空历史、关掉全部贴图、恢复通道到「仅手动」以外的清数据动作 |
| 崩溃可回退 | 透明/亚克力/嵌入导致异常 → 下次启动降级并说人话 |

## 1. 更新通道

### 1.1 入口

| 位置 | 控件 | 文案 |
| --- | --- | --- |
| 设置 · **关于** | 下拉 | 标签 `更新通道`；项：`正式` / `预览`（默认正式） |
| 设置 · 关于 | 次要按钮 | `检查更新`（可与现有检查更新合并为同一按钮，通道只影响查哪条流） |
| 托盘 | 可选 | 不放通道切换；避免误触 |

不要版本号墙、不要强制升级对话框挡截图。

### 1.2 状态

| 状态 | UI |
| --- | --- |
| 空闲 | 下拉 = 磁盘值；改完即写盘 |
| 检查中 | 底栏或按钮旁：`正在检查更新…` |
| 已是最新 | `已是最新版本。` |
| 有更新 | 系统对话框或气泡：`发现新版本。` + `下载` / `稍后`（正式/预览标明通道名） |
| 下载中 | `正在下载更新…`；可取消 |
| 失败 | 见 §1.3 |

### 1.3 失败句

| 情况 | 句 |
| --- | --- |
| 网络失败 | `检查更新失败，请稍后再试。` |
| 通道无包 | `这个通道暂时没有可用更新。` |
| 下载失败 | `下载更新失败，请稍后再试。` |
| 未接线 | `更新检查尚未在本机启用。` |

## 2. 崩溃 / 透明兜底

目标：任务栏透明、亚克力、网速嵌入等搞挂进程或拖死 explorer 时，**下次启动能用**，并告诉用户降了什么。

### 2.1 行为

| 触发 | 下次启动 |
| --- | --- |
| 上次异常退出且「任务栏效果」曾开 | 自动关效果 → 档位回系统默认；底栏/气泡见下句 |
| 上次异常且网速曾「钉任务栏」 | 改桌面悬浮（同现有嵌入失败回退） |
| 连续两次启动 30s 内再崩 | 进入「安全设置」：效果关、嵌入关、只留托盘+截图 |

不自动改用户自选的网速颜色；不删截图文件。

### 2.2 状态句

| 情况 | 句 |
| --- | --- |
| 因崩溃关掉任务栏效果 | `上次异常退出，已暂时关闭任务栏效果。` |
| 因崩溃改悬浮网速 | `上次异常退出，网速已改回桌面悬浮窗。` |
| 安全设置 | `已用安全设置启动。可在设置里再打开任务栏效果或钉栏。` |
| 写盘失败 | `没法写入安全设置，请检查磁盘权限。` |

### 2.3 入口

无单独菜单。「关于」可一行只读：`上次启动：正常 / 已降级`（可选）。主反馈用气泡 + 设置底栏。

## 3. 截图历史

### 3.1 入口

| 入口 | 文案 |
| --- | --- |
| 托盘右键 | `截图历史`（主） |
| 设置 · 截图 | 次要按钮 `打开截图历史` |
| 松手栏 | **不**加历史键（避免栏变长）；历史不挡本次截图 |

### 3.2 UI（Operate）

- 系统窗或轻列表：缩略图 + 时间 + `复制` / `钉上` / `删除`
- 默认保留最近 **30** 条或 **7 天**（先到先限）；超额删最旧
- 磁盘目录：与「保存 PNG」同根下 `History\`（实现可调，设置里只读展示路径）

### 3.3 状态

| 状态 | UI |
| --- | --- |
| 空 | `还没有截图记录。` |
| 打开 | 列表；双击 = 复制到剪贴板 |
| 复制成功 | 气泡 `已复制。` |
| 钉上成功 | 1:1 钉图（同钉图规格） |
| 删除一条 | 无撤销；立刻从列表消失 |
| 清空 | 确认框：`清空截图历史？` / `清空` · `取消` → `已清空历史。` |

### 3.4 失败句

| 情况 | 句 |
| --- | --- |
| 读盘失败 | `打不开截图历史。` |
| 文件丢失 | `这张图找不到了。` |
| 钉失败 | `没钉上，请再试一次。` |

## 4. 贴图管理与穿透快捷键

### 4.1 贴图管理入口

| 入口 | 文案 |
| --- | --- |
| 托盘右键 | `贴图管理` → 列出当前贴图（缩略/序号） |
| 托盘 | 已有 `取消贴图穿透` 保留；管理窗内也可关穿透 |

每项：`聚焦` / `关闭` / `穿透开|关`。底：`关闭全部贴图`（确认：`关闭全部贴图？`）。

贴图窗本身仍：**无标题栏、无 ×、无穿透大按钮**（`DESIGN.md`）；穿透继续靠右键菜单 + 快捷键 + 托盘。

### 4.2 穿透快捷键

| 项 | 合约 |
| --- | --- |
| 默认 | `Ctrl+Shift+Q` 切换**当前顶层贴图**穿透（可设置·截图组改键） |
| 托盘 | `取消贴图穿透` = 关掉**所有**贴图的穿透 |
| 穿透中 | Esc 不关图（键到不了窗）；只能快捷键/托盘/管理窗收回 |

### 4.3 状态 / 失败

| 状态 | 句 |
| --- | --- |
| 穿透开 | 无句（静默）；可选气泡 `已鼠标穿透。`（默认关气泡，免吵） |
| 穿透关 | 静默或 `已取消穿透。`（托盘收回时用这句） |
| 无贴图 | `当前没有贴图。` |
| 抢键失败 | `穿透快捷键注册失败，请换一组键。` |

## 5. 放大镜

### 5.1 入口

| 阶段 | 行为 |
| --- | --- |
| 截图拖中 / 悬停选窗 | 光标旁放大镜（默认 **开**，设置·截图可关：`显示放大镜`） |
| 松手后有栏 | 镜可关；不进工具栏新键（省格） |
| 取色模式 | 镜跟随取色准星（§6） |

### 5.2 样子（Operate）

- 约 **120×120** DIP，圆或圆角矩形 2px；内为光标下像素放大（默认 **2×**）
- 底边一条小字：坐标或色值（取色时显示 `#RRGGBB`）
- 无阴影炫光、无入场

### 5.3 状态 / 失败

| 状态 | UI |
| --- | --- |
| 开 | 跟手；靠边时翻到光标另一侧 |
| 关 | 不画 |
| 多屏 DPI | 跟当前屏 DPI；失败则关镜并 hint：`放大镜在这块屏不可用。` |

## 6. 取色

### 6.1 入口

| 入口 | 文案 |
| --- | --- |
| 热键（默认） | `F2`（设置可改；**不**占用 F1 截图 / F3 贴图） |
| 松手栏 | 图标键 `Pick`（吸管），放在 `Ocr` 旁或提交组前；tooltip `取色`；**栏上无字** |
| 托盘 | 可选 `取色` |

热键进取色：全屏准星 + 放大镜；左键确认；Esc/右键取消。

### 6.2 成功 / 失败

| 状态 | 句 |
| --- | --- |
| 成功 | 写入剪贴板 `#RRGGBB`；气泡 `已复制颜色 #RRGGBB。` |
| 取消 | 静默 |
| 失败 | `取色失败，请再试一次。` |

非目标 v1：调色板窗、色史、HSL 面板（只要复制 hex）。

### 6.3 工具栏顺序（相对 P1）

在识字旁插入取色时建议：

`… Text, Ocr, Pick, Eraser | Undo, Redo | …`

`Pick` 无绘制红点。

## 7. 副屏网速

### 7.1 入口

设置 · **网速** 组末：

| 控件 | 文案 |
| --- | --- |
| 勾选 | 在其它屏幕任务栏显示网速 |
| 帮助 | `主屏仍用上面的钉栏设置。副屏各钉一条；某屏钉失败会跳过该屏。` |

默认 **关**（P2 才开能力；主屏行为不变）。

### 7.2 状态 / 失败

| 状态 | 句 |
| --- | --- |
| 成功 | 无句；各副屏槽可见 |
| 部分失败 | `有的屏幕没法钉网速，已跳过。` |
| 全失败 | `副屏网速钉不上，主屏不受影响。` |
| 单屏机器 | 勾选可点但帮助：`当前只有一块屏。` |

外观（字号/色/透明）与主屏网速设置共用。

## 9. 浅色一键亚克力

P1 已有「浅色+透明」**内联提示、不强制改档**。P2 追加**一键动作**（仍不偷偷改）。

### 9.1 入口

当 P1 §4 提示条件满足时，提示行旁或下行：

| 控件 | 文案 |
| --- | --- |
| 次要按钮 | `改用亚克力并加深网速字` |

动作（一次 Apply）：

1. 任务栏效果：开 + 档位 `亚克力`（若已是亚克力则不动档）  
2. 网速：关「背景透明」；下行/上行色若对比不足则设为深墨 `{colors.ink-light}`（仅当用户仍用默认色时；**自选色不覆盖**）  
3. 底栏：`已改用亚克力方案。`

### 9.2 失败

`没法应用亚克力方案，请手动改任务栏效果。`

取消：无按钮「撤销」；用户可自己改回。

## 10. 冒烟脚本

给拟合app / 本机验证，不是用户功能。

| 项 | 合约 |
| --- | --- |
| 入口 | 仓库脚本（如 `scripts/smoke-suite.ps1`）；**设置页不放**「跑冒烟」给普通用户 |
| 可选 | 关于组按住 Ctrl 点版本区 **5 次** 露出「开发：冒烟」——默认不做，免误触 |
| 成功 | 控制台/日志：`SMOKE PASS` |
| 失败 | `SMOKE FAIL: {步骤}`；不要弹作品集报告窗 |

覆盖建议：启动托盘、F1 出栏、复制、钉图 Esc、设置写盘、网速悬浮、通道检查 stub。

## 14. 验收（Windows 真机）

1. 关于里能切正式/预览并检查更新；失败句人话。  
2. 模拟崩溃后重启见降级气泡；截图仍可用。  
3. 托盘打开截图历史；空态句对；清空要确认。  
4. 贴图管理能关单张/全部；穿透热键与托盘收回一致。  
5. 放大镜可关；取色 F2/栏键复制 `#RRGGBB`。  
6. 副屏勾选在多屏机器生效；单屏有说明。  
7. 悬浮网速拖位能记住；钉栏失败整句不变。  
8. 浅色+透明时出现一键亚克力；点后提示可消。  
9. 日志开关默认关；打开文件夹能定位。  
10. 无代码签名步骤；冒烟仅脚本/开发入口。

Debian 远程不能声称已绿。
