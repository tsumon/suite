## 0. Taste → WPF 落点（本页怎么用 skill）

| Taste 原则 | Suite 设置页落地 |
| --- | --- |
| Anti-center / Layout diversification | **左侧导航 + 右侧单页内容**（≈ 220 / *），禁止居中 Hero、禁止一屏塞五组 |
| VISUAL_DENSITY ~5–6 | 组内紧、页内有呼吸；不是 cockpit 无空隙，也不是 gallery 大留白 |
| MOTION_INTENSITY 1–2 | **无入场、无 stagger、无 perpetual**；切页即时换内容 |
| THE LILA BAN / 单强调色 | 禁止紫粉霓虹光晕；导航选中用中性高对比 + 左侧 2px 强调条（浅色墨 / 深色近白），**不用**选区红刷整页 |
| Anti 3-column cards / Anti-card overuse | 禁止 Bento、三卡、圆角大卡片套表单；用导航分区 + 发丝/间距 |
| Deterministic type（Technical UI） | WPF：**Segoe UI + YaHei UI**（系统）；禁止 Inter / Geist 网页栈 |
| Color：禁纯黑 | 窗底用 charcoal / zinc，不用 `#000000` |
| Forms：label 清晰 | 标签在控件**左侧或上方**固定宽，帮助句在下；禁用态 Opacity 不够时改用专用 muted 色 |
| States | 空/错/已保存/禁用必须分得清（见 §6） |

Dial（本任务覆盖 baseline）：`VARIANCE=6`，`MOTION=2`，`DENSITY=5`。

## 1. `/shape`（已钉）

1. **活：** 改开关/档位；网速外观可调；任务栏槽字够大、垂直居中。  
2. **结构：** **五页** — `常规` / `截图` / `网速` / `任务栏效果` / `高级`（含关于、更新、日志、恢复默认）。**禁止**再做成单列一长页。  
3. **网速外观：** 同网速规格 §3.2。  
4. **槽成功：** 高=任务栏客户区；默认 13px；光学垂直居中；默认无框。  
5. **写入：** 改完即 `ApplySettings` + 写盘（滑块 ~200ms 防抖）。  
6. **不做：** CPU/GPU/温度/皮肤商店/插件墙；不换网页字体世界；截图工具栏视觉不进设置页美化。

## 2. 窗体几何

| Token | 值 |
| --- | --- |
| 标题 | `Suite 设置` |
| 默认客户区 | **720 × 520** DIP |
| 最小 | **640 × 480** |
| 结构 | `Grid`：列0 = 导航 **200** DIP；列1 = 1px 分隔；列2 = * 内容 |
| 底栏高 | **48** DIP（状态 + 立即保存 + 关闭） |
| 导航项高 | **36** DIP |
| 内容页边 | **20** DIP（左 16 若贴分隔） |
| 标签列宽 | **96** DIP（截图/网速表单行） |
| 小按钮宽 | **72** DIP |
| 立即保存 / 关闭 | **100** / **88** DIP |

可改大小。只有**右侧内容区**滚动；导航与底栏固定。

系统控件（CheckBox / ComboBox / Slider / Button / TextBox）。不要自绘胶囊开关、不要 Lucide/Phosphor 装饰图标墙（导航可用 Segoe MDL2 单色字形，可选）。

## 3. 色与字（可实现 token）

跟系统浅/深。下面是 **设置窗专用**；截图遮罩仍用 `DESIGN.md` 的 overlay 色。

### 3.1 浅色

| Token | Hex | 用途 |
| --- | --- | --- |
| `--set-bg` | `#F3F3F3` | 窗客户区底（非纯白满屏） |
| `--set-nav-bg` | `#EAEAEA` | 左侧导航底 |
| `--set-nav-hover` | `#E0E0E0` | 导航悬停 |
| `--set-nav-active` | `#FFFFFF` | 导航选中底 |
| `--set-nav-accent` | `#1A1A1A` | 选中左侧 2px 条 |
| `--set-surface` | `#FFFFFF` | 内容区底 |
| `--set-ink` | `#1A1A1A` | 标题 / 主标签（≥ 对比 7:1 on surface） |
| `--set-ink-secondary` | `#5C5C5C` | 正文级说明 |
| `--set-ink-muted` | `#6B6B6B` | 帮助句（≥ 4.5:1 on surface） |
| `--set-ink-disabled` | `#9A9A9A` | 禁用标签（可辨，勿用与 muted 同色） |
| `--set-line` | `#C8C8C8` | 导航|内容分隔、发丝 |
| `--set-status` | `#6B6B6B` | 底栏状态（成功） |
| `--set-status-err` | `#B42318` | 底栏失败（勿只用 muted） |

### 3.2 深色（解决「字不清」）

| Token | Hex | 用途 |
| --- | --- | --- |
| `--set-bg` | `#2B2B2B` | 外底（`DESIGN` surface-dark；**禁止 `#000`）** |
| `--set-nav-bg` | `#242424` | 导航底，略深于内容 |
| `--set-nav-hover` | `#333333` | 悬停 |
| `--set-nav-active` | `#333333` | 选中底 |
| `--set-nav-accent` | `#F0F0F0` | 选中 2px 条 |
| `--set-surface` | `#2B2B2B` | 内容区 |
| `--set-ink` | `#F2F2F2` | 页标题 / 主标签（约 15.5:1） |
| `--set-ink-secondary` | `#D0D0D0` | 勾选文案、下拉主文字（约 11:1） |
| `--set-ink-muted` | `#A8A8A8` | 帮助句（约 **7:1**；旧 `#666` on `#2B` 不足，**作废**） |
| `--set-ink-disabled` | `#7A7A7A` | 禁用（约 4.6:1，仍可读） |
| `--set-line` | `#555555` | 分隔 |
| `--set-status` | `#A8A8A8` | 成功状态 |
| `--set-status-err` | `#FF8A80` | 失败（深底上够亮） |

`DESIGN.md` 里 `{colors.settings-muted}` `#666666` **仅浅色可用**；深色设置帮助必须用 `--set-ink-muted` `#A8A8A8`。

## 4. 布局（Taste：侧栏分页）

```
┌─ Suite 设置 ─────────────────────────────┐
│ ┌──────────┬────────────────────────────┐ │
│ │ 常规     │  网速                      │ │
│ │ 截图     │  (页标题 16/600)           │ │
│ │ 网速  ●  │  12px                      │ │
│ │ 任务栏效果│  [控件行…]                 │ │
│ │ 高级     │  帮助句                    │ │
│ │          │  …滚动…                    │ │
│ ├──────────┴────────────────────────────┤ │
│ │ 状态：已保存          [立即保存][关闭] │ │
│ └───────────────────────────────────────┘ │
└───────────────────────────────────────────┘
```

- 导航五项文案固定：`常规` / `截图` / `网速` / `任务栏效果` / `高级`。  
- 选中：`--set-nav-active` + 左缘 2×16 accent + 字 600。  
- 右栏**只渲染当前页**；切换无动画。  
- 禁止：顶部 Tab 再叠侧栏；禁止把五页控件叠在一个 `StackPanel` 里用滚动冒充分页。

## 6. 写入、级联、状态

同 v1 契约（保留）：

- 改动 → 立刻 Apply + 写盘；滑块防抖 ~200ms。  
- `立即保存` = 冲刷防抖；`关闭` = 无丢弃确认。  
- 级联：PNG 目录、网速块、背景色、透明度滑块、任务栏效果子控件。  
- 上/下行不能都关：`至少显示上行或下行。`  
- 底栏成功：`已保存` / `已恢复默认。`；失败用 `--set-status-err` + 人话整句。  
- 禁用：`IsEnabled=false` **且** 标签色 `--set-ink-disabled`（深色勿只靠 0.45 透明度糊成一团）。

## 8. 反模式（Taste + Operate）

- 不要一长页堆五组 + 发丝冒充分页。  
- 不要紫霓虹、玻璃光晕、Inter、大圆角 Bento、三列功能卡。  
- 不要设置打开弹跳/stagger；不要网页 `h-screen` 思维。  
- 不要深色帮助句再用 `#666`。  
- 不要导航用 emoji。

## 9. 验收

1. 打开即见左五项；任一时刻右栏只有一页控件。  
2. 深色下页标题/勾选/帮助/禁用四级色可分辨；帮助用 `#A8A8A8`。  
3. 改开关底栏出现「已保存」；关窗无丢弃框。  
4. 网速/任务栏/截图字段不丢；无 CPU/皮肤。  
5. 对照 `joe-settings-current.png`：不再是单列滚不完的一长页。

Debian 远程不能声称已绿；Windows 真机点五页 + 深浅色各拍一张。
