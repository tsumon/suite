**依据：** `taste-skill` + `SETTINGS-PAGE-SPEC.md` v2。  
Joe 2026-09-07：分页有了，但「不够高级」。本文件只加 **可实现的表面层次**，不改字段/写入契约，**不做**作品集站（无 Bento、无紫光、无入场动画、无 Inter）。

栈：**WPF Operate**。跟码读本页 + v2；冲突时本页覆盖 v2 的「看起来平」的几何/色阶，不覆盖分组与自动保存。

## 三条高级感（先做这三件就够）

### 1. 导航做成「轨」而不是灰条列表

| 做 | 具体 |
| --- | --- |
| 选中态 | 圆角 **6** DIP 的 pill 底（`--set-nav-active`）+ **左侧不贴边的** 3×20 accent（距左 8）；字 **Semibold 600**、`--set-ink` |
| 未选 | 字 `--set-ink-secondary`；悬停仅换底 `--set-nav-hover`，**不要**整列高亮一条粗线 |
| 分隔 | 导航|内容用 **1px** `--set-line`；导航顶 12 pad 后先画页眉小字 `设置`（11/600，`--set-ink-muted`），再列五项 |
| 层次 | 导航列底比内容区 **略深一档**（深色 `#1F1F1F` vs 内容 `#2B2B2B`）；禁止两边同色糊成一片 |

### 2. 内容区用「小节头 + 发丝」控节奏，不靠大卡片

| 做 | 具体 |
| --- | --- |
| 页标题 | 右栏顶：16/600 `--set-ink`；下 **4** px 一条 **全宽发丝** `--set-line`，再 **12** 才到首控件 |
| 块与块 | 同页多块（如网速「显示」与「外观」）之间：**16** 空 + **全宽 1px 发丝**；不要 GroupBox、不要 12px 圆角白卡套表单 |
| 对齐 | 所有带标签行共用 **108** DIP 标签列（比 v2 的 96 略宽，中文更齐）；勾选左缘与标签列左缘对齐 |
| 帮助句 | 缩进与控件列对齐（不是标签列），12/400 `--set-ink-muted`；与上一控件距 **6** |

### 3. 深色「贵」在对比阶梯，不在更黑

| 角色 | Hex（深色） | 用途 |
| --- | --- | --- |
| 导航底 | `#1F1F1F` | 比内容深 |
| 内容底 | `#2B2B2B` | 主表面 |
| 选中 pill | `#3A3A3A` | 导航选中（不是更亮白块） |
| 主字 | `#F5F5F5` | 页标题、选中导航 |
| 次字 | `#D4D4D4` | 未选导航、勾选文案 |
| 帮助 | `#B0B0B0` | ≥ ~7:1 on `#2B2B2B`（比 v2 `#A8` 再抬一点可读） |
| 禁用 | `#8A8A8A` | 专用色，**禁止**只用 Opacity 0.4 |
| 底栏 | `#252525` 顶 1px `--set-line` | 与内容微弱分层 |

浅色对称：导航 `#E4E4E4`、内容 `#FAFAFA`、选中 pill `#FFFFFF` + 1px `#E0E0E0` 底边、主字 `#171717`、帮助 `#5A5A5A`。

## 导航项（实现备忘）

```
[ 设置 ]          ← 11/600 muted，不可点
  常规
  截图
  网速            ← 示例选中：pill + 左条 + Semibold
  任务栏效果
  高级
```

可选：每项左侧 Segoe MDL2 单色 16px（与字色同源），**不要**彩图标、不要 emoji。

## 底栏抬升

| 元素 | 规格 |
| --- | --- |
| 状态 | 左对齐，12/400；成功 `--set-status`；失败 `--set-status-err`（深 `#FF8A80`） |
| 立即保存 | 次要轮廓或标准系统按钮；**不要**整栏唯一大色块 CTA |
| 关闭 | `IsCancel`；与保存间距 **8** |
| 右缘 pad | **16** |
