## 0. `/shape` 五条（压缩 brief，已钉死，不问卷）

1. **活：** Joe 按 F1 截屏。悬停选窗或手拖；**松手立刻**出现对照 07 的浅色图标工具栏。点一下就能标、复制、钉、存、关。
2. **主路径：** 不是文字按钮条，不是先钉再标。自动钉仍是设置，**默认关**。
3. **栏：** 贴选区下方（不够则上方）。图标顺序见 §8 与 toolbar spec。选中工具可有红点。
4. **选区松手后：** 3px **实线蓝框**（Joe：不要虚线框）、八个锚点、尺寸片 `宽 × 高 px`（**不要**三分法虚线辅助线）。拖的过程仍是红描边、无手柄。
5. **不做：** OCR、滚动截图、GIF、取色面板、编号、双向箭头、高斯模糊、放大镜、Esc 确认框、贴图分组。不换字体世界。贴图光环 / 网速 / 设置分组不动。

假设（无问卷）：F3 = 从剪贴板贴图；形状键 v1 按下 = 矩形，椭圆下拉不阻塞；铅笔与马克笔栏上都在，至少一种能画出线。

## 2. 一句话

F1 → 全屏遮罩 → 悬停点窗或手拖 → **松手立刻**留下选区，底下出现浅色图标工具栏 → 标注或复制/钉/存/关。Esc / 右键：整次当没截过。

## 4. 状态机

```
Idle
  ├─ F1 / 托盘「区域截图」 ──► Overlay
  ├─ F3 / 托盘「贴图（从剪贴板）」──► 有图则 Pin（无选区，钉在指针附近）；无图则气泡，仍 Idle
  └─ 已有贴图上 Esc/Delete ──► 只关那一张，Idle 不变

Overlay                         ← 全屏遮罩已亮，尚未按下
  ├─ 鼠标移动 ──► HoverWindow（高亮命中的窗/控件）
  ├─ 命中桌面且无窗 ──► 高亮当前监视器工作区
  ├─ 左键按下 + 移动 ≥ 4 物理像素 ──► Drag
  ├─ 左键按下 + 抬起 < 4px ──► CommitWindow ──► Annotate
  ├─ Esc / 右键抬起 ──► Cancel ──► Idle
  └─ 再按一次截图热键 ──► 忽略（忙）

HoverWindow                     ← Overlay 的子态，不是独立模态
  └─ 高亮随指针走；规则同 Overlay 的按下 / Esc

Drag
  ├─ 移动 ──► 更新矩形 + 尺寸片（红描边，无锚点，无工具栏）
  ├─ 抬起、矩形 ≥ 4×4 ──► 看设置（§6）
  ├─ 抬起、矩形 < 4×4 ──► 若此刻仍有窗高亮则 CommitWindow，否则留在 Overlay
  └─ Esc / 右键 ──► Cancel ──► Idle

CommitWindow / CommitDrag
  ├─ PinAfterCapture = false（默认）──► Annotate
  ├─ PinAfterCapture = true 且未按 Shift ──► PinAndCopy ──► Idle
  └─ PinAfterCapture = true 且 Shift+抬起 ──► Annotate

Annotate                        ← 默认主路径。选区留在原地，工具栏已出现
  ├─ 无绘制工具时拖选区内 ──► 平移选区（保持 W×H），松手重裁
  ├─ 点绘制工具 ──► 在选区上画；选中键红点
  ├─ 撤销 / 重做 ──► 栈空则该键禁用（仍在栏上，变淡）
  ├─ 复制 / Enter / 左键双击 ──► 写剪贴板（按设置可存盘），不钉 ──► Idle
  ├─ 钉图 / 中键 ──► 写剪贴板 + Pin ──► Idle
  ├─ 保存 ──► 存 PNG；失败气泡，会话可继续
  └─ Esc / 关闭 / 右键 ──► Cancel ──► Idle
     （文字输入中的 Esc：先退出文字框；再按一次才整次取消）

Pin                             ← 会话已结束；每张贴图独立
  ├─ 拖、滚轮、Alt+滚轮、右键菜单 ──► 仍 Pin
  └─ Esc / Delete / 菜单「关闭」──► 关这一张
```

**忙碌：** `IsBusy` 为真时热键与托盘「区域截图」无操作、不叠第二层遮罩。

**受保护窗口：** 命中区按真实窗矩形高亮；截出来是黑块。不破解 `SetWindowDisplayAffinity`。不要为此弹错误——黑块本身就是结果。

## 5. 快捷键

### 5.1 全局

对照 Joe 对 `06-control-hotkeys.png` 的标注（该文件磁盘内容是贴图「转换」页，**热键不听那页控件**）。

| 键 | 行为 |
| --- | --- |
| 默认 `F1`（无修饰） | 进入 Overlay。设置可改截图热键。 |
| 默认 `F3`（无修饰） | 从剪贴板贴图。与托盘「贴图（从剪贴板）」同一动作。本轮设置页不新开一行。 |
| 注册失败 | 托盘气泡 + 设置状态：「热键 {键} 注册失败（可能被占用）。请在设置中改键。」不循环抢注。 |

调研里 Snipaste 官网把 F1/C/F3 写成取色。**听 Joe：F1 截屏、F3 贴图。** 取色面板本轮不做。

### 5.2 Overlay / HoverWindow / Drag

| 键 / 鼠标 | 行为 |
| --- | --- |
| Esc | 整次取消。**不要** Snipaste 那种 Esc 确认框（`03` 里勾着；本产品 distill 掉）。 |
| 右键抬起 | 同 Esc |
| 左键点击（位移 < 4px） | 截当前高亮窗/控件，进入 Annotate |
| 左键拖（位移 ≥ 4px） | 手选矩形；拖起来后不再跟窗 |
| 松手 | 默认进 Annotate（§6） |
| 鼠标移动 | 只更新高亮或矩形，不截 |

v1 **不做**：方向键微移、`=`/`-` 调遮罩、放大镜、取色、全屏十字线（`01` 里该项未勾）。

### 5.3 Annotate（松手后，对照 `03-snip-hotkeys.png`）

| 键 / 鼠标 | 行为 |
| --- | --- |
| Esc | 整次取消（不钉、不复制、不存盘） |
| 文字输入中的 Esc | 先退出文字框，不退出整次；再按一次 Esc 才整次取消 |
| 右键（点「取消」或空白） | 同 Esc |
| Enter | 复制到剪贴板，然后退出截屏 |
| 左键双击 | 同 Enter |
| 中键单击 | 贴到屏幕（Pin），然后退出截屏 |
| 关闭键 | 同 Esc |
| 复制键 | 同 Enter |
| 钉图键 | 同中键 |

不为每个绘制工具再占一组全局键。切换靠点栏。

### 5.4 贴图（会话已结束）

| 键 / 鼠标 | 行为 |
| --- | --- |
| Esc 或 Delete | 关**当前焦点**这一张。其它贴图不动。 |
| 左键拖 | 移动 |
| 滚轮 | 缩放，锚点尽量跟指针；缩放后仍按像素近邻 |
| Alt+滚轮 | 透明度 15%–100% |
| 右键 | 菜单：不透明 100% / 75% / 50% / 25%；鼠标穿透；关闭 |
| 穿透开启时 | 键鼠穿过这张图；托盘「取消贴图穿透」才能收回 |

穿透中 Esc **不**关图（键到不了这窗）。只能托盘收回穿透再关。

## 6. 松手之后（默认主路径 = 工具栏）

设置 `截完后自动钉成贴图` 默认 **关**。

| 条件 | 松手后 |
| --- | --- |
| 关（默认） | Annotate：选区留下，工具栏立刻出现 |
| 开 + 未按 Shift | 立刻 PinAndCopy，跳过工具栏 |
| 开 + Shift | Annotate |

**Annotate 必须同时做到：**

1. 选区像素 1:1 留在原处，窗外继续压暗。
2. 松手后铬切到**实线**蓝框 + 锚点 + 尺寸片（**无**虚线框、**无**三分辅助线；见 toolbar spec）。
3. 浅色图标工具栏贴在选区**下方**（下方不够则上方），对照 07。即时出现，无入场动画。
4. 点复制 / 钉 / 存 / 关闭才结束会话（存失败不结束）。
5. **无绘制工具时**，在选区预览上左拖可**平移**选区（保持 W×H，夹在监视器并集内）；锚点仍负责缩放；选中绘制工具后拖动仍是画。

**PinAndCopy 必须同时做到：**

1. **一比一。** 贴图内容 DIP 宽高 = `像素宽高 × 96 / 该监视器 DPI`。`Zoom = 1`。禁止 Stretch、禁止给图加内边距。
2. **钉在选区原点。** 左上角对齐选区左上角。多屏跨 DPI 用**选区所在屏**的 DPI。
3. **剪贴板写入**同一份像素。写失败：仍钉；气泡「无法写入剪贴板。」
4. **可选存 PNG** 仅当设置勾了。存失败：钉和剪贴板仍算成功；气泡「无法保存文件：…」
5. **遮罩立刻卸掉。** 贴图不是从 0 放大弹入。允许光环 120ms 淡入。
6. **近邻缩放。** 滚轮放大后用 NearestNeighbor。

最小选区 4×4 物理像素。小于此：不当成一次截图。对照 `02`「隐藏 1x1 提示」：不要为 1×1 残片出栏。

## 7. 微信式选窗

公开 API：`WindowFromPoint` + UI Automation 取屏上矩形。禁止逆向 Snipaste。对照 `02-snip-behavior.png`：默认自动检测窗口、自动检测界面元素。

### 7.1 悬停

- 指针下的可见窗或控件：红描边 3px（`{colors.accent}`，与 `01` 边框宽度 3 一致），窗外保持压暗，窗内 **零压暗**。
- 嵌套控件：优先更小、更内层的可见矩形，不要永远只框顶层窗。
- 命中桌面：高亮该监视器工作区。
- 不要标题气泡、不要「已选中 XXX.exe」。高亮就是反馈。
- 跨屏：高亮矩形可画到它所在的每一块遮罩上。

### 7.2 点击

位移 < 4px 的按下-抬起 = 提交**当前高亮矩形**，走 §6。不要再等第二次确认。

### 7.3 手拖优先

一旦位移 ≥ 4px：丢掉窗高亮，改画手拖矩形。之后即使指针回到某窗上，也还是手拖，直到抬起或 Esc。

拖中铬：红直角描边 3px、尺寸片、**无**锚点、**无**工具栏、**无**蓝变换框。

### 7.4 遮罩自身

命中测试必须穿过遮罩窗，测下面的真实窗。遮罩不能把自己当成选中目标。

## 8. 工具栏（主 UI，不是岔路）

**形状**（矩形 / 椭圆）· **曲线** · **铅笔** · **马克笔** · **马赛克** · **文字** · **橡皮** | **撤销** · **重做** | **关闭** · **钉图** · **保存** · **复制**

`Shape, Curve, Pencil, Marker, Mosaic, Text, Eraser, Undo, Redo, Close, Pin, Save, Copy`

| 键 | 外观 | v1 行为 |

| Curve | 折线/曲线 | 能画出一条线 |
| Pencil | 尖笔 | 手绘实线。与马克笔至少一种能画；另一种可先等同不同粗细/透明度，**按钮不能空** |

| Mosaic | 像素格 | 涂抹打码 |
| Text | 大写 T | 点选区出输入框 |

## 9. 遮罩 UI

允许：

- 全屏截图像素作底 + 未选区压暗（`{colors.overlay-dim}`）。
- 十字光标（不要 `01` 未勾的全屏十字线）。
- 左上角一句：`悬停点窗，拖动手选。松手出工具栏。Esc 取消。`
- 尺寸片：选区外侧上沿，格式 `235 × 172 px`（数字 + 空格 + × + 空格 + 数字 + 空格 + `px`）。
- 拖中：红色直角描边 3px，无控制点。
- 松手后：蓝色**实线**描边 3px、八个锚点、工具栏（Joe：不要虚线框 / 三分辅助线）。见 toolbar spec。

禁止：

- 中文文字按钮条（现行 `AnnotationWindow` 那种「矩形/箭头/文字/…」是反例）。
- Lucide 现代栏、暗色玻璃、胶囊 FAB。
- 松手即钉（除非设置勾了自动钉）。
- 把 `plans/joe-hate-toolbar-ref.png` 再写成反例。

`01` 的放大镜选项、`02` 的截屏历史 / 音效：本轮不做。

## 10. 贴图视觉（钉上去之后）

对照 `04-pin-display.png`：贴图要能从桌面里分出来。本产品用 **向外彩虹光环（发光彩虹）**，不换 Qt 窗口阴影算法。

- 只有位图 + 向外光环。光环在像素外扩散，命中区 = 位图。见 `DESIGN.md` Elevation。
- **Joe（2026-09）：** 白/黑单色光晕在浅/深桌面都难辨；改为多层彩虹描边 + 外向软模糊，色相缓慢循环。禁止不透明白底硬框。主题只调光环透明度，不再强制白/黑。
- 无标题栏、无「×」、无「穿透」按钮、无说明条。
- 悬停：光环可略加强；光标改为可拖。不要滑出一条厚 caption。
- 右键才出菜单。菜单用系统样式。
- 多张贴图互不编组。v1 不做吸附、备份、GIF、虚拟桌面。
- `04` 的默认不透明 100%、`05` 磁盘上那页「使用截屏时的位置」：钉在选区原点即满足。其它贴图行为页勾选本轮不搬进设置。

## 11. Esc 契约（硬）

| 阶段 | Esc / 右键 | 剪贴板 | 磁盘 | 贴图 |
| --- | --- | --- | --- | --- |
| Overlay / Hover / Drag | 整次取消 | 不写 | 不写 | 不出现 |
| Annotate（非文字输入） | 整次取消 | 不写 | 不写 | 不出现 |
| Annotate 文字输入中 | 先退出输入框 | 不动 | 不动 | 不出现 |
| 已钉的贴图有焦点 | 只关这一张 | 不动 | 不动 | 其它贴图保留 |
| Idle | 无 | — | — | — |

「整次取消」= 用户回头看桌面，应觉得没按过热键。不准留残影遮罩、不准留下 1×1 贴图、不准把半次截图写进剪贴板。不要 Esc 确认对话框。

## 13. 运动与反模式

- 遮罩出现 / 消失：即时。
- 工具栏随松手出现：即时。不要淡入、不要从 0 放大。
- 贴图：禁止从 scale 0 弹出。
- 窗高亮跟随指针：直接换矩形，不要弹性 overshoot。
- 图标悬停：浅底；按下略压。不要弹跳、不要 tooltip 动画。
- Operate 工具：禁止紫渐变、Inter、Lucide 装饰、大圆角卡、入场编排。

## 14. 验收（实现对照，不在本文写代码）

1. F1 → 悬停记事本客户区 → 单击 → 记事本那块留在原地，**下方出现对照 07 的浅色图标栏**；尚未钉。
2. F1 → 拖一块 → 松手 → 实线蓝框 + 八锚点 + `宽 × 高 px` + 工具栏。
3. 点复制 / Enter / 左键双击：剪贴板能贴到画图，遮罩没了，没有新贴图。
4. 点钉图 / 中键：1:1 钉在选区原点，遮罩没了。
5. F1 → Esc：桌面无遮罩、无新贴图、剪贴板未被这次写入。
6. 工具栏上点关闭：同上，整次取消。
7. 勾上自动钉 → 拖一块松手：跳过工具栏，直接钉。
8. 高 DPI：钉的 DIP 尺寸 = 像素 / 缩放。
9. 栏上能认出 13 个图标，顺序与 §8 一致；不是「矩形/箭头/文字」那种字。
10. 现行贴图顶栏（「× / 穿透 / 滚轮缩放…」）不得再出现。

Debian 远程不能声称工具栏已绿。下一轮 Windows 真机对照 07。
